# kikiride
Stworzenie pliku opisu (README.md): Komenda echo "# kikiride" >> README.md utworzyła plik z nagłówkiem projektu.

Inicjalizacja lokalnego repozytorium: Komendą git init utworzyłeś czyste repozytorium Git w odpowiednim folderze (~/Desktop/kukiride).

Zatwierdzenie zmian (Commit): Plik README.md został dodany (git add) i zapisany w historii jako pierwszy commit o treści "first commit".

Zmiana nazwy gałęzi: Pomyślnie zmieniłeś nazwę domyślnej gałęzi z master na standardową main (git branch -M main).

Połączenie z GitHubem: Powiązałeś lokalny projekt ze zdalnym repozytorium na koncie GitHub (git remote add origin [https://github.com/dejf96/kikiride.git](https://github.com/dejf96/kikiride.git)).

Wysłanie kodu na serwer (Push): Komenda git push -u origin main wysłała plik na serwer i zalogowała Cię przez przeglądarkę. Plik README.md jest już bezpieczny i widoczny w internecie na Twoim profilu!

Co jeszcze zostało do zrobienia (kolejne kroki projektu):

Uzupełnienie treści README.md: Obecnie Twój plik zawiera tylko napis # kikiride. Warto wkleić tam rozbudowany opis gry Roblox (ten, który przygotowaliśmy wcześniej z sekcjami: O Projekcie, Mechanika, EXP, Tuning).

Stworzenie i dodanie plików strony WWW: Musisz utworzyć pliki index.html oraz style.css (za pomocą edytora nano w Git Bash).

Wysłanie aktualizacji na GitHub: Po utworzeniu stron należy dodać je do Gita komendami git add ., git commit -m "Dodanie strony internetowej" i git push.

Włączenie GitHub Pages (Darmowy Hosting): Trzeba wejść w ustawienia repozytorium na GitHub.com (Settings -> Pages) i włączyć publikację strony z gałęzi main, aby wygenerować publiczny link www dla nauczyciela.

Chcesz teraz przejść do edycji pliku README.md w Nano, czy wprowadzamy od razu pliki index.html i style.css?
